# 연습 평가 답변의 한국어 영어 번역 설계

## 목적

연습자가 영어 표현을 몰라 답변에 한국어 문장을 섞어 입력한 경우, 평가 결과의 전체 교정본에서 해당 내용을 자연스러운 영어로 확인할 수 있게 한다.

## 범위

- 연습 평가용 `buildEvalPrompt`의 `corrected_answer` 지침을 강화한다.
- 답변에 한국어가 포함되면 의미를 유지한 영어로 번역하도록 명시한다.
- 기존 영어 구간은 문법 오류와 어색한 표현을 교정한다.
- 현재의 `corrected_answer` JSON 필드와 웹의 전체 교정본 표시를 그대로 사용한다.

## 제외 범위

- 별도 `translated_answer` 필드 추가
- API 응답 스키마, 데이터베이스, 웹 타입 또는 화면 구조 변경
- 별도 번역 API 호출이나 서버 전처리 단계 추가

## 동작 계약

평가 모델은 `corrected_answer`를 다음 규칙으로 생성한다.

1. 답변에 한국어 문장이나 구절이 있으면 자연스러운 영어로 번역한다.
2. 이미 영어인 내용은 의미·구조·분량을 최대한 유지하면서 문법과 어색한 표현을 교정한다.
3. 최종 `corrected_answer`에는 한국어를 남기지 않는다.
4. 결과는 기존 JSON 형식과 `*_ko` 필드의 한국어 규칙을 유지한다.

## 테스트

프롬프트 단위 테스트에서 한국어 번역 지침과 최종 답변에 한국어를 남기지 않는 지침이 포함되는지 검증한다. 구현 전 테스트가 실패하는 것을 확인하고, 프롬프트 변경 후 통과시킨다.

## 오류 처리 및 호환성

프롬프트 문구만 변경하므로 기존 저장 결과와 API 계약에는 영향을 주지 않는다. 모델이 잘못된 JSON을 반환하는 기존 오류 처리와 원문 보존 동작도 변경하지 않는다.
